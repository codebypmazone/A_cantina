# A Cantina

Simulação do app de pedidos da cantina: login, cadastro, cardápio, carrinho, forma de pagamento, retirada imediata ou agendada (hoje ou amanhã).

**Acesse:** https://codebypmazone.github.io/A_cantina/

## Fotos dos pratos
As imagens ficam na pasta `img/`, com os nomes definidos em `MENU`, no início do `<script>` do `index.html` (ex.: `pao-de-queijo.jpg`). Sem a foto, aparece um emoji.
